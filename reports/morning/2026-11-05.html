全球新聞晨報｜選後普漲與油價急跌，AI供應鏈分化｜2026-11-05

2026年11月5日（星期四）

美國期中選舉後全球股市普漲、油價急跌及美債殖利率回落，但AI資料中心股承壓；Qualcomm與Arm財報顯示算力需求仍在擴張，台日晶片鏈與中港市場走勢分化。

閱讀次數：載入中

一、今日市場主旋律

市場主線由「買入所有AI」轉向「選後政策、能源與算力回報重新定價」。民主黨取得美國國會兩院控制權後，美股道瓊大漲3.03%，標普500與小型股亦廣泛走高；資料中心相關股票卻因潛在監管與地方電力、稅收政策而承壓。這說明風險偏好回升沒有直接轉化為AI基建全面上漲。Fed十月按兵不動，11月4日美國官方2年與10年殖利率分別回落至4.58%及4.90%，美元指數亦走弱；較低折現率提供估值喘息，但不能代替雲端投資現金回報。

布蘭特與WTI結算均下跌逾8%，市場押注選後美伊戰爭可能較早緩和；戰事、荷姆茲航運及實際供給仍需事實確認。油價回落有助通膨預期，卻壓低能源股，讓金融、消費與醫療更受青睞。半導體則呈現基本面與股價分離：Qualcomm公布與Amazon的多年資料中心合作並維持2027財年資料中心收入目標，Arm營收年增27%、資料中心權利金翻倍；但日本半導體股下跌、台灣大盤盤中劇烈震盪，韓國記憶體市場雖回升仍有外資賣壓。中國與香港股票反彈，反映政策支持及風險偏好改善，尚不能直接推論終端需求已復甦。今日須把選後寬鬆交易、AI盈利驗證與能源地緣風險分開觀察。

二、重點摘要

  • 美國選舉後風險資產普漲。民主黨取得國會兩院控制權後，道瓊升1,569.40點至53,356.12，標普500升1.58%。Why it matters：政治不確定性下降，資金轉向金融、消費和醫療；具體立法仍待確認。
  • AI資料中心與大盤分化。Reuters及AP均指出市場擔憂新國會對資料中心、能源及AI監管加強審視。Why it matters：算力需求增長仍需與許可、電力及資本回報分別評估。
  • 油價單日重挫。布蘭特1月期貨結算94.62美元、跌8.7%；WTI結算88.12美元、跌8.3%。Why it matters：能源通膨壓力暫降，但價格反映和平押注，不代表停火已實現。
  • 美債殖利率與美元下行。美國財政部2年期4.58%、10年期4.90%，分別較前日下降3及5基點；美元指數約101.52。Why it matters：折現率與匯率條件稍鬆，科技估值仍受監管與現金流限制。
  • Qualcomm擴張資料中心業務。公司公告與Amazon多年產品合作，重申2027財年資料中心收入50億美元目標，汽車晶片季收入首破20億美元。Why it matters：AI加速器與伺服器供應商競爭增加，訂單轉成實際交付仍需核對。
  • Arm財報揭示伺服器需求。季度收入14.4億美元、年增27%；資料中心權利金年增一倍，但整體權利金6.7億美元低於市場預估。Why it matters：架構滲透率與短期出貨節奏不同，不能只看營收超預期。
  • 亞洲呈現鮮明分化。日本日經跌1.42%，台灣加權跌0.83%；KOSPI升0.62%，滬深300升2.31%，恒生升1.67%。Why it matters：美股選後上漲未在前一時區同步出現，區域晶片曝險與政策敏感度各異。
  • 歐洲與美國波動率改善。STOXX 600漲1.82%至657.40，VIX跌至16.61。Why it matters：市場風險溢價收斂，但當日盤中及資料商數字須區分。

  • 美國｜期中選舉。AP與Reuters報導民主黨取得國會兩院控制權，總統與國會分治；美股廣泛上漲。Why it matters：財政、AI監管和能源政策談判的路徑改變，個別法案尚未定案。
  • 加拿大｜能源敏感度。11月4日國際原油結算急跌，未見加拿大央行同日新政策利率決定。Why it matters：加拿大能源出口與通膨預期可能反向受影響，須核對後續官方數據。
  • 歐洲｜金融及清潔能源。歐股11月4日反彈，Reuters稱銀行與再生能源股受選舉結果提振。Why it matters：ECB評估油價回落與成長時，仍面對能源安全及企業投資不確定性。
  • 英國｜股市與央行。富時100收10,829.21、升1.79%；英格蘭銀行11月5日將公布利率決議。Why it matters：市場反彈與新利率預測須分開判讀。
  • 日本｜晶片股回檔。文化日後首個交易日，日經收62,188.63、跌1.42%，TOPIX收3,895.38、跌0.89%。Why it matters：半導體與AI估值疑慮壓過油價下降的短期利多。
  • 韓國｜記憶體股與資金流。KOSPI收5,683.80、升0.62%；Aju Press報導外資淨賣出約2.51兆韓元。Why it matters：指數回升不代表HBM供應鏈的資金壓力完全消失。
  • 中國｜政策支持與A股反彈。滬深300收4,101.33、升2.31%，市場消化此前流動性措施。Why it matters：股價反彈仍需企業盈利、信用與訂單證明。
  • 香港｜風險偏好回升。恒生指數收23,919.50、升1.67%，高於盤中23,827.11的媒體快照。Why it matters：正式收盤顯示午後買盤，不能用盤中數字代替終值。
  • 台灣｜大幅震盪後收低。加權指數收42,948.91、跌358.63點，盤中高低相差近1,886點；台積電收跌。Why it matters：晶片龍頭及外資流向仍是亞洲AI交易的壓力測試。
  • 國際政治與能源｜美伊戰事。油價因選後和平預期急跌；目前沒有可據此認定已停火或荷姆茲航運恢復正常的正式證據。Why it matters：能源風險溢價可能快速回補。
  • 央行｜Fed、ECB、BOJ。11月4日沒有三家央行的新利率決定，美國公債殖利率隨油價和選舉消息回落。Why it matters：後續政策仍以正式通膨、就業與決議為準。

  • Apple與Tesla：Apple先前警示記憶體成本，Tesla與其他高耗能AI建設者面對許可及電網風險；不將選舉後政策可能性視作已生效規則。
  • NVIDIA、Broadcom、Intel、Palantir、Coinbase、SpaceX：AI與加密敏感股在選後大盤反彈中表現分化，需以公司公告、訂單和現金流判斷，不能用指數漲幅替代個股表現。

六、半導體供應鏈

已檢查最近一份正式11月3日亞洲收盤報的台韓HBM、晶圓代工、光模組與ASIC主題，並重新搜尋最近24小時的公司公告、Reuters與AP、台韓日正式收盤及美國AI股走勢。11月4日沒有正式亞洲收盤報可直接引用；以下重新分析，不沿用前報的KOSPI終值或舊事件判讀。

  1. Qualcomm資料中心與Amazon：Qualcomm公告多年資料中心合作，維持2027財年50億美元收入目標。這為AI加速器、CPU、網路與伺服器系統帶來新競爭，但實際量產、封裝及記憶體採購仍需驗證。
  2. Arm伺服器架構：Arm第二財季營收14.4億美元、資料中心權利金年增一倍，整體權利金仍低於分析師預期。伺服器CPU架構滲透與授權收入提高，晶片出貨節奏及客戶組合仍是供應鏈風險。
  3. AMD GPU與CPU：AMD前日財報顯示資料中心營收年增97%，11月4日市場將注意力轉向AI投資監管和回報。代工、HBM與封裝需求需以實際交貨和毛利而非財測單獨推估。
  4. 台灣晶圓代工與封裝：台灣加權11月4日跌0.83%，台積電收跌，盤中大幅震盪。TSMC先進製程與CoWoS產能可能仍緊，但股價走勢提示短線資金風險高於新增訂單證據。
  5. 韓國HBM與記憶體：KOSPI回升0.62%，外資卻淨賣出約2.51兆韓元。Samsung、SK Hynix與Micron的HBM認證、良率和DRAM價格仍須分開核對，不能由指數反彈推定訂單改善。
  6. 日本設備與測試：文化日後日經跌1.42%，半導體相關股票承壓。ASML、Applied Materials、Lam Research及日本設備商的訂單與交期比單日股價更能確認晶圓廠資本支出。
  7. ASIC與光互連：前份亞洲收盤報的光模組與ASIC主題仍受選後AI監管討論影響。Broadcom及雲端客製晶片供應鏈需以實際合約、交換器與光模組交付核對，而非複製前日利多敘事。
  8. 電力與AI Server：選後資料中心審查疑慮及油價急跌同時改變基建估值。機房電力、冷卻與地方許可可能成為伺服器上架速度的限制，尚無證據顯示已公布的晶片需求被取消。

九、市場動態

11月4日的資金流向不是單純回到科技股，而是選後風險重新分配。道瓊升3.03%、標普500升1.58%，那斯達克升1.44%，小型股也上升；醫療、金融和一般消費的表現顯示買盤擴散。反過來，資料中心建設及部分與現屆政府政策關聯較深的股票受壓，因新國會可能重新審視地方稅收優惠、電網負擔和AI規範。這些仍是政策預期，不是已實施的限制。VIX降至16.61，說明大盤對政治結果的短期不確定性下降，卻不能消除高估值AI資產的個別風險。

跨資產對此形成第二條主線：WTI與布蘭特結算下跌逾8%，美債2年與10年期殖利率分別下降3及5基點，美元指數走低，黃金與白銀反彈。能源成本下降可能改善家庭實質購買力與企業毛利，對能源股則造成壓力；油價跌勢建立在美伊戰爭可能更早緩和的市場判斷上，並非停火確證。利率回落使長久期科技估值受益，但AI建設是否能帶來足夠收入與現金流仍是獨立問題。Qualcomm與Arm新公布的資料中心業務數字證實需求並未消失，同時Arm整體權利金低於預期、Qualcomm的50億美元仍屬未來目標，提示訂單、出貨和收入之間有時間差。

亞洲市場比美歐更早收盤，不能以美股夜間漲勢倒填台日韓當日分析。日本晶片股下跌、台灣指數劇烈震盪後收低；韓國指數微升但外資淨賣出，中港則隨政策與風險偏好反彈。後續要觀察亞洲11月5日能否承接美股廣泛反彈，以及油價、殖利率與AI監管消息是否繼續同方向變動。若能源風險重新升溫或實際資料中心限制出現，今日的估值修復可能迅速反轉。

十、投資重點

  1. 區分選後大盤反彈與資料中心相關股的個別政策風險。
  2. 核對AI供應鏈的訂單、實際出貨、毛利及自由現金流。
  3. 將Qualcomm資料中心收入目標與已認列收入分開。
  4. 檢查Arm授權收入增長與權利金低於預期的原因。
  5. 使用各地正式收盤而非盤中價比較亞歐美市場。
  6. 追蹤油價結算、荷姆茲航運與正式外交結果。
  7. 以財政部日線和央行正式決議更新利率假設。
  8. 觀察台韓外資流向及TSMC、HBM、設備訂單，不以單日股價代替基本面。
