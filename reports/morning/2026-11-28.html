全球新聞晨報｜AI反彈遭高利率與能源風險考驗｜2026-11-28

2026年11月28日（星期六）｜資料截止：台北時間08:33

美股短市由科技股帶動反彈，中國穩市政策推升亞洲股市；但美債殖利率回升、美元偏強與中東供應風險仍考驗AI投資回報。逐一核對11月27日全球正式收盤，並揭露油價與行情來源差異。

閱讀次數：載入中

一、今日市場主旋律

全球主線是AI股票在急跌後反彈，卻同時遇上更高的折現率與能源風險，尚不能把股價修復等同投資回報獲得證明。美國感恩節後僅交易半天，Nasdaq升2.3%，Broadcom與雲端平台股帶動科技類股；但NVIDIA僅升0.8%，市場仍要求龐大資料中心支出轉成現金流。Fed面對偏熱的10月PCE，11月27日美國2年與10年期公債官方殖利率升至4.69%與4.94%，美元維持高位，長天期科技資產估值仍受壓。亞洲的另一條主線來自中國國常會擴大國家資金穩市作用，滬深300大漲4.17%，韓國在穩市基金預期下升4.34%，日本記憶體及設備鏈也回補；台灣卻僅漲0.40%，且權值與中小型股背離。歐洲科技與礦業上揚，DAX和STOXX 600收高，但歐元區情緒指標走弱。能源方面，霍爾木茲與沙烏地設施事件增加供應風險，油價卻在11月27日收低，顯示地緣溢價與需求、獲利了結互相拉扯。中國政策落地規模、AI伺服器出口合規、BOJ通膨反應及下次Fed決策，將決定這波薄量反彈能否轉為較持久的風險偏好修復。

二、重點摘要

  • 美股短市全面上揚。S&P 500升1.6%、Nasdaq升2.3%，為震盪一周收尾。Why it matters：科技反彈擴散至小型股，但半日成交不能單獨證明趨勢反轉。
  • AI龍頭表現不齊。AP記錄Broadcom升3.8%、Amazon升4%、NVIDIA僅升0.8%，Anthropic升11%。Why it matters：投資人重新區分平台營收、晶片交貨與估值風險。
  • 中國穩市訊號引發急升。國常會要求強化國家資金與長期資金作用，滬深300升4.17%。Why it matters：政策降低短期流動性風險，實際資金規模仍待公布。
  • 韓日半導體股回補。KOSPI升4.34%，日經升2.11%，Kioxia與NVIDIA儲存合作受到關注。Why it matters：HBM以外的SSD與GPU資料路徑也成為AI供應鏈焦點。
  • 台股廣度落後。加權指數升0.40%，最新亞洲收盤報記錄台積電撐盤而櫃買下跌。Why it matters：全球AI回補沒有均勻擴散至台灣中小型供應商。
  • 歐股連續修復。STOXX 600收643.85，DAX官方終值25,441.24。Why it matters：科技與礦業領漲，但歐元區經濟情緒降至95.8。
  • 美債殖利率回升。美國財政部11月27日2年與10年殖利率分別為4.69%與4.94%。Why it matters：利率上升抵消部分AI股反彈對估值的支持。
  • 油市與金屬走勢分叉。Reuters報WTI結算83.08美元、Brent 95.44美元，黃金現貨在19:01 GMT漲2.1%。Why it matters：中東供應風險仍在，但價格並非單向追漲，報價時點必須區分。

  • 美國｜科技股反彈。感恩節後短市S&P 500收7,297.49，AP與Reuters均指出AI估值及獲利疑慮仍在。Why it matters：下周完整交易量與利率方向比單日升幅更能檢驗反彈。
  • 加拿大｜貿易與利率。本次未核實加拿大央行新決議；美國關稅提案與北美跨境供應鏈仍是風險。Why it matters：製造業成本須以正式規則及適用範圍衡量。
  • 歐洲｜科技領漲而景氣偏弱。STOXX 600升1.08%，歐元區11月經濟情緒降至95.8。Why it matters：市場回補與實體需求尚未同步。
  • 英國｜大型股回升。FTSE 100收10,698.81、升0.84%。Why it matters：能源及全球營收權重使英股對油價與美元仍敏感。
  • 日本｜通膨與科技。東京11月核心CPI年增2.9%，日經與TOPIX雙雙收高。Why it matters：BOJ升息預期可能限制科技股估值擴張。
  • 韓國｜記憶體與穩市。KOSPI收4,915.68，市場關注擴大證券市場穩定基金。Why it matters：政策預期與HBM需求共同驅動反彈，但基金細節尚待確認。
  • 中國｜國家隊訊號。國常會要求強化中央匯金及長期資金角色，CSI 300收4,063.06。Why it matters：後續要核對資金實際投入及民間盈利改善。
  • 香港｜跟隨內地回升。恒生指數公司顯示恒指收22,694.77、升2.11%；前一份Asia Close的22,675.47與官方值不同，本文採官方指數公司時點。Why it matters：政策傳導方向明確，精確點位以正式收盤為準。
  • 台灣｜權值支撐。加權收39,308.08、升156.27點。Why it matters：台積電與中小型股的分化使供應鏈判讀不能只看加權指數。
  • 國際政治與能源｜中東供應。Reuters報霍爾木茲油輪與沙烏地設施事件，沙烏地能源部稱Jazan煉廠部分作業暫停。Why it matters：實際減供與修復時程將決定油價溢價。
  • 央行｜Fed、ECB、BOJ。Fed面對高通膨，歐洲領袖選定Hernández de Cos為ECB接班人，日本通膨再加快。Why it matters：三地政策差異影響美元、日圓、殖利率及全球科技股。

六、半導體供應鏈

已先檢查11月27日正式Asia Close對GPU、Kioxia、台積電、韓國HBM、先進封裝、設備與AI伺服器的分析，再核對近24小時公司公告、Reuters、AP及最新市場終值；以下重新判讀當日供應鏈主線。

  • GPU與儲存：Kioxia公告與NVIDIA進行以SSD及SCADA擴大GPU記憶體有效容量的概念驗證。若技術驗證成功，AI推論的資料路徑可能增加高效SSD需求，但目前尚非商業出貨承諾。
  • HBM與DRAM：韓股11月27日急升，三星與SK海力士獲資金回補。市場重新定價記憶體需求，但股價不能證明新產能或合約價格已變更。
  • 晶圓代工：台積電支撐加權，台灣中小型科技股卻未同步上升。晶圓需求仍須看正式客戶拉貨、良率與資本支出，不能由指數單日漲幅推算。
  • 先進封裝：中國政策引導資金流入半導體與先進封裝類股。政策交易提升相關估值，但對全球封裝供給的實際影響仍取決於設備交付及量產驗證。
  • 設備與測試：日本測試、設備股領漲，歐洲ASML等科技股亦回升。Applied Materials與Lam Research的接單仍應以公司財報為準，不能把地區股市反彈視為新增訂單。
  • ASIC與網通：Broadcom股價升3.8%，反映市場重新買入客製晶片及網路互連主題。後續需核對平台客戶的資本支出是否轉為可持續的晶片需求。
  • AI Server與出口合規：前一日關於NVIDIA東南亞伺服器出貨暫停的報導仍缺公司逐筆確認。製造商須依正式許可及終端用途安排交貨，交期風險可能沿電源、散熱及組裝鏈傳遞。
  • 能源與資料中心：油價及中東供應事件提高資料中心能源與物流成本的不確定性。GPU、HBM及伺服器需求預測應同時核算電力、冷卻與建置時程。

九、市場動態

11月27日的股市回升呈現兩種不同的資金驅動：美國與歐洲是AI科技股在急跌後的重新配置，中國與韓國則疊加明確或預期中的市場穩定政策。美國Nasdaq領漲、Russell 2000也參與，顯示回補不只集中於單一巨頭；然而NVIDIA漲幅落後Broadcom，說明市場仍在區分GPU、ASIC與平台公司的盈利路徑。Kioxia與NVIDIA的儲存概念驗證提供新的技術方向，卻尚不能推算SSD、HBM或先進封裝訂單。台灣加權收紅但櫃買下跌，則顯示資金仍偏好流動性佳的權值股，供應鏈廣度未完全恢復。中國大漲有政策支持，但國家隊的規模和執行節奏尚待公布。美元保持偏強、美債2年與10年殖利率同步上行，使長天期成長股的估值仍受折現率擠壓。黃金與白銀上漲、VIX下行、油價收低卻仍含中東供應溢價，反映避險與風險回補同時存在，不能用單一指標概括情緒。加拿大、歐洲及亞洲製造商亦需面對美國關稅提案與伺服器出口合規不確定性。下周若完整交易日成交量擴大、利率穩定，反彈可信度才可能提高；若油價重新上升或政策細節不及預期，資金可能再次回到大型流動性標的及防禦資產。研究重點應放在正式公司文件、交易所終值與政策落地，而非由半日股價推導長期需求。

  1. 比較AI相關公司資本支出與實際收入、現金流的變化。
  2. 追蹤美債殖利率和美元對科技股折現率的影響。
