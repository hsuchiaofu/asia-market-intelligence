一、今日市場主旋律

週一開盤前的真正主線，是AI需求與AI供應鏈合規風險開始分開定價。上週五美國科技與台日韓晶片市場急跌，反映投資人要求更清楚的算力採購資金來源、收入品質及資本支出回收期。週日美國財長要求輝達回答先進晶片對中銷售的合規問題，將治理與出口許可推至供應鏈前端；這是調查與提問，尚非違規結論。Fed面對通膨仍須謹慎，週五美債殖利率下行卻未穩住科技股，顯示槓桿縮減比折現率改善更有力。美元未顯著走強，VIX則急升；資金流向呈現現金與公債避險，而非全面轉進單一資產。中國政策方面，上次LPR持平，仍待新措施證實內需和國產AI算力需求；韓國HBM、台灣代工與日本設備的實際訂單也不能用跌幅代替。能源與國際政治加入新變數：COP31因化石燃料轉型措辭未能達成協議，利比亞俄艦遭疑似無人機攻擊，荷莫茲航運風險延續。上述週末事件均發生在週五正式收盤後，尚未反映在股市及原油結算價；今日重點是核對油輪通行、晶片合規回覆，以及週一開市市場的廣度。日本因勤勞感謝日休市，亞洲訊號需由其他市場確認。

二、重點摘要

  • 美國要求輝達說明對中晶片交易。財長貝森特週日稱仍需釐清公司出口合規與內部責任；CBS原訪問及Reuters報導一致，尚未作成違規裁定。Why it matters：許可、合規成本與訂單交付可能比單季營收更影響估值。
  • COP31未能通過總體協議。聯合國與AP均確認，化石燃料措辭分歧使安塔利亞會議無協議落幕。Why it matters：能源轉型政策的跨國一致性減弱，企業投資假設須分地區檢視。
  • 利比亞俄艦遇襲疑雲。AP引述利比亞官員稱疑似烏克蘭海上無人機；Reuters引述東部政府稱初步調查指向無人機，責任歸屬仍待核實。Why it matters：黑海以外的地中海航運安全風險可能升高。
  • 週五AI股票重挫仍是最近正式收盤。美股那斯達克跌5.28%、標普500跌3.70%，台韓日科技權重市場亦大幅下跌。Why it matters：下一交易時段須確認賣壓是否擴散至信用與非科技產業。
  • 週五債券與波動率發出避險訊號。美國財政部2年及10年公債殖利率分別為4.63%與4.92%；VIX收35.89、升26.20%。Why it matters：殖利率下行未抵銷AI板塊的風險溢價上升。
  • 日本今日股市休市。日本交易所確認11月23日勤勞感謝日不交易。Why it matters：日經與TOPIX仍須以11月20日終值標示，不能把亞洲其他市場早盤變動套用至日股。
  • 週末加密資產資料商口徑分歧。Basis Desk稱22日UTC日終比特幣61,083美元、以太幣1,720美元，YCharts同日時間標記不同。Why it matters：週末反彈並不足以證明週一AI股票止跌。

  • 美國｜晶片合規。貝森特於CBS訪問要求輝達釐清銷售及管理責任；Reuters另行報導其發言。Why it matters：出口審查不確定性進入公司治理層面。
  • 加拿大｜貿易與能源。最近24小時未核實新的央行決議或重大公司公告；北美市場須觀察美國AI調整是否傳至加拿大資源與金融股。Why it matters：不應把美股科技跌勢直接等同加拿大本地需求變化。
  • 歐洲｜COP31與市場。歐盟反對未提及化石燃料的草案；上次STOXX 600正式收盤下跌2.00%。Why it matters：能源轉型及工業資本支出政策出現更多分歧。
  • 英國｜COP31立場。英國與歐盟等反對欠缺化石燃料措辭的文本；富時100上週五收跌1.02%。Why it matters：英國能源、保險與公用事業需分別評估政策及油價風險。
  • 日本｜國定假日。日本交易所確認23日勤勞感謝日休市，上週五日經與TOPIX均急跌。Why it matters：日本設備股對週末新消息的價格反應須等下一有效交易日。
  • 韓國｜HBM與央行。KOSPI上次收跌5.21%；本週韓國央行決議值得留意。Why it matters：記憶體出口與資金成本的訊號應分開檢查。
  • 中國｜政策與晶片許可。上次LPR維持不變，美國對中先進晶片合規追查新增不確定性。Why it matters：國產替代需求可能上升，但不能視為已確認訂單。
  • 香港｜科技曝險。恒指上週五跌1.89%，平台及晶片相關估值繼續承壓。Why it matters：後續須核對企業現金流與中國政策，而非只看全球AI情緒。
  • 台灣｜代工與封裝。台股上週五跌6.23%，台積電等權重影響顯著；今日尚無正式收盤。Why it matters：出口合規消息可能牽動代工交付預期，仍須正式文件證實。
  • 國際政治｜利比亞。俄羅斯軍艦在班加西受損；AP與Reuters對疑似無人機相符，攻擊者尚未確證。Why it matters：地中海軍事與航運風險需追蹤後續調查。
  • 能源｜氣候與航運。COP31未達協議，荷莫茲週末航運事件仍待進一步海事核實。Why it matters：供給安全與長期轉型政策同時影響能源風險溢價。
  • 央行｜Fed、ECB、BOJ。截至資料截止未見新政策決議；市場仍聚焦本週美國PMI與通膨、歐洲工資及日本政策路徑。Why it matters：利率預期會改變科技股折現與匯率條件。

六、半導體供應鏈

已檢查最近正式11月20日亞洲收盤報的台積電、三星、SK海力士、GPU、HBM、設備、先進封裝及出口許可主題，並就主要公司與供應鏈主題重新搜尋最近24小時資料。今日新增可交叉核實事件以輝達合規追問為核心；以下以最新正式收盤與已核實公告分析供應鏈。

  1. GPU與出口合規。美國財長週日要求輝達交代對中晶片交易的合規責任，CBS訪問和Reuters報導互相印證。供應鏈需區分正式許可、實際交付與已入帳收入，不能預設調查結果。
  2. 晶圓代工。台積電所在台股週五下跌6.23%，輝達的對中合規問題週日新增。若客戶許可審查延長，代工排程與營收可見度可能受影響，仍待公司文件確認。
  3. HBM及記憶體。三星、SK海力士所在KOSPI週五下跌5.21%，美國晶片股也同步承壓。記憶體供應鏈需追蹤客戶庫存、HBM良率和實際價格，而非直接把股價當作訂單取消。
  4. ASIC與網路。Broadcom等公司受週五美國AI板塊重估牽動，週日未核實重大新訂單公告。客製化加速器可能分散GPU供應集中，但客戶融資與使用率仍決定採購速度。
  5. 先進封裝。輝達此前正式供應鏈合作仍涉及台灣及其他封裝夥伴，週日未核實新的產能改動。封裝排程將同時受GPU需求與出口合規審查影響。
  6. 半導體設備。日本日經與TOPIX週五大跌，週一休市；ASML、Applied Materials與Lam Research未見最近24小時可核實的新指引。設備訂單須等待正式財報與客戶資本支出，而不能由假日缺席的報價推估。
  7. AI伺服器與電力。週五AI基建股承受資金去槓桿，週日COP31未達協議凸顯能源政策分歧。資料中心交付仍取決於互連、電力與電價，跨國能源政策不一致可能拉長規劃期。

週一市場面對的是一組時點不同的訊號。上週五已成交的行情顯示，AI供應鏈高權重市場承受共同去槓桿；那斯達克、台股、韓股及日股的跌幅，都大於多數傳統產業權重市場。這說明資金正在重新評估晶片需求的資本來源、雲端客戶採購承諾與實際應用收入，卻不能單靠價格證明GPU、HBM或封裝訂單已取消。週日貝森特的最新發言令輝達出口合規從背景風險變成可追問的具體問題：若許可、內控或資訊披露進展不清，市場可能要求更高風險溢價；但調查尚未得出結論，不能預先定罪。美債殖利率上週五走低，美元沒有明顯避險升值，VIX則急升，代表資金更關注減少股票波動曝險，科技股未從低殖利率即時受惠。週末比特幣與以太幣在一個資料商口徑下反彈，但加密資產交易時間和流動性與股票不同。能源方面，COP31未能取得化石燃料共識，利比亞軍艦遇襲及先前荷莫茲航運風險使供給與政策的不確定性並存；週五油價並未反映週日新事件。中國上次LPR不變，對亞洲晶片需求的政策支持仍需實際信用及訂單資料驗證。今日日本休市，故亞洲資金流與市場情緒須先看台灣、韓國、香港及中國的交易廣度，再待日股復市。投資研究應把已成交收盤、週末新聞、未證實的調查結果及未來政策決議清楚分層，觀察信用利差、油輪通行和企業現金流是否支持風險價格回穩。
